# Expense Tracker

A full-stack expense tracking application built with React and Django REST Framework.

## Live Demo

[View Live Demo](https://expense-frontend-tau-eight.vercel.app/)

## Backend

[Backend Repository](https://github.com/xuannhi-tran/expense-api)

## Features

- User authentication
- Add, edit and delete expenses
- Search and filter expenses
- Spending summary
- Spending by category
- REST API integration
- User-specific expense data

## Tech Stack

### Frontend

- React
- Axios
- CSS

### Backend

- Django
- Django REST Framework
- PostgreSQL
